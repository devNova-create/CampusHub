# CampusHub 🎓

CampusHub is a comprehensive **Student Management System** designed to simplify academic administration and improve communication between students, faculty, and administrators. The application provides an intuitive platform for managing student records, attendance, marks, notices, and user profiles through role-based access.

---

## 📌 Features

### 👨‍🎓 Student Module
- Secure student login
- View personal profile
- Check attendance records
- View academic marks/results
- Receive campus notices and announcements
- Update profile information

### 👨‍🏫 Admin Module
- Secure administrator login
- Manage student records
- Add, edit, and delete student information
- Record and update attendance
- Manage student marks
- Publish notices and announcements
- View and manage user profiles

### 📊 Attendance Management
- Record daily attendance
- Update attendance records
- View attendance history
- Attendance tracking for each student

### 📝 Marks Management
- Add examination marks
- Update marks
- View student performance
- Maintain academic records

### 📢 Notice Board
- Publish campus announcements
- Share important notifications
- Display notices to all students
- Manage notice updates

### 👤 Profile Management
- Student profile management
- Admin profile management
- Update personal information
- View account details

## 🚀 Installation

### Prerequisites

- Android Studio (Latest Version)
- JDK 17 or above
- Gradle
- Firebase Project Configuration

### Steps

1. Clone the repository

```bash
git clone https://github.com/devNova-create/CampusHub.git
```

2. Open the project in Android Studio.

3. Sync Gradle dependencies.

4. Add the required `google-services.json` file to the `app/` directory.

5. Build and run the application on an emulator or Android device.
